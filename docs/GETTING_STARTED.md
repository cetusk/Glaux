# はじめての Glaux

Glaux をインストールしてから、1 曲作って書き出すまでの流れです。困ったときは [`TROUBLESHOOTING.md`](TROUBLESHOOTING.md) を見てください。

## 1. インストールと、はじめの確認

1. [Releases](https://github.com/cetusk/Glaux/releases) から `Glaux-<版>-windows-x64-setup.exe`(インストーラー)か
   `Glaux-<版>-windows-x64.exe`(単体)をダウンロードして開きます。
   「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」を選びます(署名をしていないため)。
2. 初めて起動すると「Glaux へようこそ」が開き、次を確かめます。足りないものはその場で用意できます。

   | 項目 | 無いとき |
   |---|---|
   | 音の出力 | 設定の「オーディオ」で出力デバイスを選び直す |
   | AI のチャット | Claude Code か Codex CLI を入れてログインし、Glaux を起動し直す(下の 2 章)。AI 無しでも作曲・ミックス・書き出しはすべて使えます |
   | SoundFont | 「GM 音源を取得」(GeneralUser GS、約 32MB)か、手持ちの `.sf2` を追加。無くても内蔵のシンセ・ドラムで作れます |
   | デモ曲 | 「デモ曲を開く」で、内蔵の音源だけで作ったドラムンベースの写しが開きます |

   この画面は、設定(右上の歯車)→「表示」→「はじめの確認」からいつでも開けます。

## 2. AI のチャットを使えるようにする

チャットは、PC に入れてログインしてある CLI を Glaux が呼び出して使います。どちらか一方で構いません。

| 相手 | 入れ方 |
|---|---|
| Claude(Claude Code) | `npm i -g @anthropic-ai/claude-code` → `claude` を一度起動してログイン |
| GPT(Codex CLI) | `npm i -g @openai/codex` → `codex login` |

入れた後は Glaux を起動し直します。相手・モデル・考える深さは、チャット欄の上で切り替えます。
AI が使えるのは Glaux のツールだけで、PC のファイルの読み書きやコマンドの実行はさせません。

## 3. 1 曲作る

### 曲を作る・開く

左上の曲名のメニューから「新しい曲」「開く」。曲は 1 曲 1 フォルダ(`MySong.glaux`)で、
既定ではユーザーのフォルダの `Music\Glaux\` に作られます。保存は自動です(編集のたびに書かれます)。

### AI に頼む

チャット欄に、したいことを普通の言葉で書きます。

- 「120 BPM の 8 小節のローファイ・ヒップホップのドラムとベースを作って」
- 「サビだけもっと盛り上げて」「ベースを少し前に出して」
- 「この曲のキーとコード進行を教えて」「全体の音量を配信向けに整えて」

AI は曲を直接編集し、タイムラインにすぐ反映されます。1 ターンの編集はチャットの「このターンを取り消す」で
まとめて戻せます。実行中も次の指示を書いておけます(今の指示が終わったら送られます)。
入力欄が空のときに ↑ を押すと、前に送った指示を呼び出せます。

範囲を指定したいときは、ルーラーをドラッグして小節を選ぶ・ピアノロールを開く・音作りを開くと、
その対象が指示に添えられます(チャット欄の上に札が出ます)。

### 自分で打ち込む

| したいこと | 操作 |
|---|---|
| トラックを足す | タイムラインの下の「トラックを追加」(MIDI・音声・バス・MIDI ファイル) |
| クリップを作る | MIDI トラックの空いた所をダブルクリック(ピアノロールが開く) |
| ノートを置く・消す | ピアノロールでクリック / 右クリック。Ctrl+A で全選択、↑↓ で移調、Q でクオンタイズ |
| 音を固定する | ピアノロールで音を選んで K(もう一度で外す)。固定した音は、AI の作り直し・編集では変わりません |
| 音色を変える | トラックの見出しの音源名 → 内蔵シンセ・ドラム・SoundFont・CLAP から選ぶ |
| 音作り・エフェクト | トラックの見出しの「インスペクター」のボタン(右に開く)。ミキサーではエフェクトをノード表示でつなげる |
| 横に拡大・縮小 | タイムラインの上で Ctrl+ホイール。ルーラー左の「全体」で曲全体を表示 |
| 音声を入れる | 音声トラックの空いた所をダブルクリック(WAV / MP3 など)。録音はヘッダーの録音ボタン |
| 再生 | Space。←/→ で前後の小節、Home/End で先頭/終わり |
| 取り消す | Ctrl+Z / Ctrl+Y。履歴の一覧から、途中の 1 件だけを打ち消すこともできます |

### 曲を設計する・案を聴き比べる

左上の画面の切り替え(タイムライン・ミキサー・設計)で「設計」を開くと、曲の計画と今の曲の実際を並べて見られます。

| 欄 | 見られること・直せること |
|---|---|
| 曲全体 | ジャンル・雰囲気・キー・盛り上がりの型・守ること。項目をその場で直せます |
| 盛り上がり | 区間ごとの盛り上がりの曲線(計画)と、今の曲から測った値(点線)。点を動かす・区間ごとの平行移動・境目(つなぐ / 段差) |
| パートごとの音域 | パートごとの計画の音域の帯と、実際に鳴っている音域。帯を動かす・広げる、「実際を計画に」 |
| パートの役割 | パート × 区間の表(主役・前面・支え・背景・気配・鳴らさない の 6 段階)。マスを選んで数字キー、ドラッグで塗る |

計画が無い曲は、AI に「曲全体とパートの計画を作って」と頼むと作られます(今の音から推定した計画は、確かめてから採用します)。
計画と実際のずれは右の欄に出て、AI は作る・直すときにそれを読みます。所を選んでから「この所について AI に頼む」で、
その所を対象にして頼めます。計画の変更は、下の欄の「計画の履歴」に理由と一緒に残ります。

好みが分かれる直し(「Drop 2 をもっと厚くする案を 3 つ出して」など)は、AI が曲を変えずに **案** として出し、
設計画面の上に並びます。

- 「聴き比べる」で、今(A)と案(B)を同じ範囲で繰り返し鳴らし、同じ位置のまま切り替えられます(音量はそろえてあります)
- 案が 2 つ以上あれば「まとめて聴き比べる」で、今と案(4 つまで)を A・B・C … で切り替えられます
- 「変わる所」の区間を押すと、その区間で聴き比べます
- 「採用」で案の音が曲に当たり、案の計画が今の計画になります。同じ頼みから出たほかの案は一緒に片付きます。
  採用は、どの画面の Ctrl+Z でも計画ごと 1 回で戻せます

### 聴き比べる・整える

「ミキサー」に切り替えると、全トラックの音量・パン・送りとメーターを見渡せます。右端のモニター列では、
モノラルやスマホ・ノート PC のスピーカーの聞こえ方に切り替えて確かめられます(書き出しには入りません)。

履歴の各編集のヘッドホンのボタンで、その編集の前(A)と今(B)を、音量をそろえて聴き比べられます
(ループ中ならその区間、範囲を選んでいればそこ、無ければ今の位置から 8 小節。再生位置はそのままで切り替わります)。

## 4. 書き出す

右上の「書き出し」から、曲全体(ミックス)・トラックごと(ステム)・MIDI を書き出せます。
形式は WAV / FLAC、44.1k / 48kHz、16 / 24 / 32bit。「音量」で -14 LUFS(配信向け)などを選ぶと、
音量をそろえて、ピークをリミッタで抑えます。
