# Glaux で作れる曲のジャンル(2026-09-23 時点)

今の機能とプラグインで、どのジャンルがどこまで作れるかの整理。機能が増えたら更新すること。
前提の環境: 内蔵の音源・エフェクト + SoundFont(FluidR3_GM)+ CLAP プラグイン Surge XT。

## 使える道具

| 分類 | 内容 |
|---|---|
| 音源 | subtractive(シンセ全般。unison でスーパーソウ)、drum(ドラムシンセ、GM 配置)、pluck(ギター・ベース・ハープの撥弦モデル)、sampler(WAV のワンショット)、SoundFont(FluidR3 で GM 128 音色: ピアノ・ストリングス・ブラス等)、CLAP プラグイン(Surge XT はプリセット 2,944 個。AI がプリセット選び・つまみ操作・オートメーションまで可能) |
| エフェクト | eq(3 バンド)、compressor、reverb、distortion、amp(ギターアンプ)、sidechain(ポンピング)。トラックにもマスターにも挿せる。Surge のトラックでは Surge 内蔵のディレイ・コーラス等も使える |
| 表現 | 奏法(パームミュート・スタッカート・アクセント・ビブラート・ベンド)、ピッチカーブ(手描き、CLAP にも届く)、ベロシティ、オートメーション(音量・パン・音色・エフェクト・マスター・CLAP のつまみ)、ループクリップ、拍子・テンポの途中変更 |
| 音声 | 録音(鼻歌・楽器)、WAV / MP3 等の取り込み、テンポ追従(タイムストレッチ)、パート分離(内蔵: 打楽器 / 音程楽器、Demucs: 4 パート)、譜起こし(単旋律・和音) |
| 入力 | MIDI キーボード(サステインペダル・ピッチベンド込み)、MIDI 録音 |

## ジャンル別の向き・不向き

◎ 得意 / ○ 作れる(一部に限界) / △ 苦手

| ジャンル | 向き | 主に使うもの | 足りないもの |
|---|---|---|---|
| EDM(ハウス・トランス・フューチャーベース) | ◎ | Surge / スーパーソウ、キック + sidechain のポンピング、フィルタスイープのオートメーション、ループ | センド(複数トラックで共有するリバーブ等) |
| シンセウェイブ・80s | ◎ | Surge のアナログ系プリセット、reverb、ゲートっぽいドラム | 内蔵のコーラス・ディレイ(Surge 側で補える) |
| アンビエント・ドローン | ○ | Surge のパッド、長い reverb、ゆっくりしたオートメーション | ディレイ・シマー系の空間エフェクト |
| ロック・メタル | ○ | pluck + amp + distortion、パームミュート・ベンド、drum | MIDI ギターのリアルさに限界。生ギターの録音はモノラル |
| ポップス・J-POP の伴奏 | ○ | SoundFont のピアノ・ストリングス、drum、ベース | ボーカル処理(音程補正・ディレイ・ハモリ加工) |
| ヒップホップ・トラップ | ○ | 808 はサイン波 + ピッチカーブでグライド、ハイハットの連打、パート分離でのサンプリング | 取り込み音声がモノラルになる(ステレオ感のあるサンプルが痩せる) |
| Lo-fi・チルホップ | ○ | SoundFont のエレピ、drum、パッド | テープ・レコード風の質感エフェクト、スウィング(ヨレ)の自動化 |
| ゲーム BGM・劇伴(小編成) | ○ | SoundFont のオーケストラ、Surge のパッド | GM 音源の質感、ストリングスの奏法(レガート等) |
| オーケストラ(本格) | △ | SoundFont | 音色の質・奏法の種類ともに不足 |
| ジャズ | △ | SoundFont のピアノ・ウッドベース・ドラム、和声解析(analyze_harmony) | スウィング感、アドリブの細かなニュアンス |
| 弾き語り・生演奏中心 | △ | 録音、テンポ追従 | ステレオ録音、音程補正、複数テイクの編集 |

## まとめ

- **得意なのはシンセ主体の電子音楽**。Surge + sidechain + オートメーションがそろい、AI がプリセット探しからつまみの微調整まで担える。
- **ポップス・ロック・劇伴は「作れるが音質は GM 音源なり」**。ピアノ専用・ストリングス専用などの高品質な SoundFont に替えると一段上がる。
- **生音・歌もの中心は苦手**。取り込み音声がモノラルになり、ボーカル向けの処理が無い。

## 伸ばすと効果が大きいもの(優先順)

1. **CLAP エフェクトプラグイン**: Dragonfly Reverb・LSP・Filterjam などで空間系・マスタリングが一気に充実する(CLAP 第 2 段階の残り)
2. **センド / リターン**: 複数トラックでリバーブ・ディレイを共有する
3. **ステレオ音声**: 取り込み・録音・パート分離をステレオのまま扱う(今は `load_wav_mono` で平均してモノラル化)
4. **スウィング(グルーヴ)**: Lo-fi・ヒップホップ・ジャズのノリ
