# Glaux でできること: AI の能力と作れる曲のジャンル(2026-09-23 時点)

Glaux の AI が何を知覚し・何を操作し・どう表現できるか、そしてそれらと音源・エフェクトで
どのジャンルがどこまで作れるかの整理。機能が増えたら更新すること
(AI の道具を足したら「AI ができること」、音源・エフェクトを足したら「使える道具」とジャンル表)。
前提の環境: 内蔵の音源・エフェクト + SoundFont(FluidR3_GM)+ CLAP プラグイン Surge XT。

---

## 1. AI ができること

AI(チャットのヘッドレス Claude、または外部の MCP クライアント)は MCP ツール 34 個で Glaux を操作する。
すべての編集は人間と同じ履歴に残り、取り消せる。

### 1.1 感覚(何を知覚できるか)

| 感覚 | ツール | 分かること |
|---|---|---|
| **楽譜を読む** | get_project | 全トラック・クリップ・ノート・音源とつまみ・テンポ・拍子・曲の構成(セクション)。include_notes: false で構造だけ俯瞰 |
| **音を聴く(曲・ミックス)** | analyze_audio | オフラインで鳴らして、ラウドネス(統合・短期の推移・LRA)・ピーク・True Peak・ダイナミクス・帯域バランス・明るさ・発音の数・ステレオの広がりと位相。per_track でトラックごとのバランスと、トラック間の周波数のかぶり(マスキング: どの帯域で何が何を覆っているか) |
| **音色を聴き分ける(1 音)** | analyze_sound | サンプル・音声クリップ・トラックの 1 音を細かく数値化: 包絡(立ち上がり・減衰・持続・余韻)、音程(学習済みモデル SwiftF0 で推定。ずれ・しゃくり・ビブラート)、スペクトル(明るさとその推移=フィルタの開閉、ノイズっぽさ)、倍音(奇数/偶数・減り方・金属っぽさ・波形の推定)、言葉での要約。さらに学習済みモデル CLAP で「聴いた」印象を言葉で(何の楽器らしいか・明るさ・質感・雰囲気。追加モデルの取得が必要) |
| **音を聴き比べる** | compare_sounds | 2 つの音(サンプル・クリップ・トラックの 1 音)の距離(音色・音量の時間変化)と、明るさ・立ち上がり・減衰・長さ・ノイズ・倍音・音程の違い、寄せ方の手がかり、CLAP での印象の近さ |
| **拍を感じる(音声)** | analyze_beats | 取り込んだ曲・ループ・録音のテンポ(小数まで)・拍子・小節頭の位置・テンポの揺れ(打ち込みか人の演奏か)。テンポ追従の元テンポに使える |
| **音楽理論の目** | analyze_harmony | キーと、小節ごとのコード進行(推定値。確からしさ付き) |
| **リズム感** | analyze_rhythm | スウィング比(ストレート / シャッフル)・グリッド(2 分割 / 3 連)・シンコペーション・ずれの大きさ(機械的 / 人間的)・密度 |
| **つまみの意味** | list_params | 内蔵の音源・エフェクトのつまみ全部に、範囲と「聴感上の効果」の説明が付く。CLAP プラグインのつまみは名前で絞り込み、画面上の表示(例「-48.00 dB」)も読める |
| **人間の操作を知る** | get_history | 誰が(人間 / AI)何をしたか。チャットでは前回からの人間の編集が自動で伝わる |
| **いま見ている場所** | UI からの文脈 | 選択した小節範囲・ピアノロールで開いているクリップ・音作り中のトラックが指示に自動で添えられる |

### 1.2 手(何を操作できるか)

| 分野 | ツール | できること |
|---|---|---|
| **作曲** | apply_commands | トラック・クリップ・ノートの追加・変更・削除、クリップの分割・ループ化、テンポ・拍子(途中変更も)、曲名、構成マーカー(Aメロ・サビ等) |
| **ノートの一括編集** | transpose_notes / shift_notes / quantize_notes / scale_velocity | 移調、時間移動、クオンタイズ、強弱の一括調整 |
| **音作り(内蔵)** | apply_commands(set_device / set_param / add_effect) | 音源 5 種の選択とつまみ、エフェクトの追加・つまみ・バイパス |
| **音作り(外部プラグイン)** | list_plugins / list_plugin_presets / load_plugin_preset / list_params | CLAP 音源(Surge XT 等)の選択、プリセット選び、公開されたつまみの操作。CLAP エフェクト(Surge XT Effects・Dragonfly Reverb・LSP 等)をトラック・マスターに挿してつまみ・オートメーションで動かす |
| **似た音を作る** | match_sound / find_similar_presets | サンプルに合わせて内蔵シンセのつまみを自動で探す(約 20 秒)。CLAP プラグインのプリセットから近いものを探す(初回は索引作りに数分)。UI からは音声クリップのメニュー「この音に似せた内蔵シンセのトラックを作る」 |
| **音色の道具箱** | list_presets / save_preset / load_preset / delete_preset、list_soundfonts / set_soundfont_instrument | 自作プリセット(全プロジェクト共通)、SoundFont の GM 楽器一式 |
| **ミックス** | apply_commands | 音量・パン・ミュート・ソロ、EQ・コンプ・サイドチェイン、マスターのエフェクト |
| **時間変化** | apply_commands(set_automation_points / set_master_automation_points) | 音量・パン・音色・エフェクト・CLAP のつまみ・マスターを曲線で動かす(フェード、ビルドアップ、フィルタスイープ) |
| **音声素材** | import_sample / import_audio_clip / transcribe_audio / separate_audio | 音声の取り込み、譜起こし(単旋律・和音)、パート分離。テンポ追従は set_clip_stretch |
| **安全網** | checkpoint / revert_to / revert / undo / redo | 試行錯誤の足場。複数コマンドを 1 回の取り消しにまとめられる |

### 1.3 表現(どんな演奏ができるか)

**奏法(ノートごとに付ける)** — 楽器によって効くものが違う(効かない組み合わせは無視される)

| 奏法 | subtractive | drum | pluck | sampler / sf2 | CLAP | 効果 |
|---|---|---|---|---|---|---|
| パームミュート | ○(こもった刻み) | − | ◎(本命) | − | − | 減衰を速く・暗く |
| スタッカート | ○ | − | ○ | ○ | ○ | 音価を半分に |
| アクセント | ○ | ○ | ○ | ○ | − | 強く(楽器により明るく) |
| ビブラート | ○ | − | ○ | ○ | − | 後半に深くなる揺れ |
| ベンド | ○ | − | ◎(チョーキング) | ○ | − | 全音下から滑り上がる |

CLAP の列: スタッカートは音の長さで表現するので効く。ほかの奏法は内蔵音源の中の処理なのでプラグインには届かない
(同じ効果はピッチカーブで作れる)。

**そのほかの表現**

- **ピッチカーブ**: 1 音ごとに音程を自由な曲線で動かす(しゃくり・ポルタメント・ダイブ・808 のグライド)。
  内蔵音源にも CLAP 音源(1 音だけの音程変化として)にも届く
- **ベロシティ**: 1 音ごとの強さ。楽器によって音量だけでなく明るさも変わる
- **タイミングのゆらぎ**: analyze_rhythm で既存のノリを測り、同じスウィング・同じずれ方で書ける(ヒューマナイズ)
- **ループ**: 1〜2 小節のパターンを繰り返す(ドラム・リフ)
- **ダイナミクスの流れ**: 音量・音色のオートメーションで、ビルドアップや展開を作る

### 1.4 AI にまだできないこと

- **生の音を聴くこと**: analyze_audio / analyze_sound は数値と言葉の要約(CLAP の印象語も目安)。「この音が気持ちいいか」は直接は分からない(人間の感想が頼り)
- **どんな音でもそっくりに作ること**: 内蔵シンセの自動合わせはシンセらしい単音なら「よく似ている」まで届くが、
  生楽器・複雑な音は「似ている部分がある」止まり。プリセット検索と人間の耳での仕上げが前提
- **演奏をリアルタイムに聴くこと**: 人間の録音・MIDI 入力は取り込めるが、弾いている最中に反応はできない
- **プラグインが公開していない設定**: 例えば Surge XT の LFO のテンポ同期・モジュレーションの割り当て。
  プリセットには入っているので「それらしいプリセットを探す」で代用する。細かい調整は人間がプラグインの画面で行う
- **歌声を作ること**: 歌声合成・ボーカルの音程補正は無い(鼻歌の譜起こしはできる)
- **MIDI の CC(モジュレーションホイール等)の打ち込み**: 時間変化はオートメーションで代用する

## 2. 使える道具

| 分類 | 内容 |
|---|---|
| 音源 | subtractive(シンセ全般。unison でスーパーソウ)、drum(ドラムシンセ、GM 配置)、pluck(ギター・ベース・ハープの撥弦モデル)、sampler(WAV のワンショット)、SoundFont(FluidR3 で GM 128 音色: ピアノ・ストリングス・ブラス等)、CLAP プラグイン(Surge XT はプリセット 2,944 個) |
| エフェクト | eq(3 バンド)、compressor、reverb、distortion、amp(ギターアンプ)、sidechain(ポンピング)。トラックにもマスターにも挿せる。CLAP エフェクト(Surge XT Effects 等)も同じチェーンに挿せる |
| 音声 | 録音(鼻歌・楽器)、WAV / MP3 等の取り込み、テンポ追従(タイムストレッチ。元のテンポは自動検出できる)、パート分離(内蔵: 打楽器 / 音程楽器、Demucs: 4 パート)、譜起こし(単旋律・和音) |
| 入力 | MIDI キーボード(サステインペダル・ピッチベンド込み)、MIDI 録音 |

## 3. ジャンル別の向き・不向き

◎ 得意 / ○ 作れる(一部に限界) / △ 苦手

| ジャンル | 向き | 主に使うもの | 足りないもの |
|---|---|---|---|
| EDM(ハウス・トランス・フューチャーベース) | ◎ | Surge / スーパーソウ、キック + sidechain のポンピング、フィルタスイープのオートメーション、ループ | センド(複数トラックで共有するリバーブ等) |
| シンセウェイブ・80s | ◎ | Surge のアナログ系プリセット、reverb、ゲートっぽいドラム | 内蔵のコーラス・ディレイ(Surge 側で補える) |
| アンビエント・ドローン | ○ | Surge のパッド、長い reverb、ゆっくりしたオートメーション | ディレイ・シマー系の空間エフェクト |
| ロック・メタル | ○ | pluck + amp + distortion、パームミュート・ベンド、drum | MIDI ギターのリアルさに限界。生ギターの録音はモノラル |
| ポップス・J-POP の伴奏 | ○ | SoundFont のピアノ・ストリングス、drum、ベース | ボーカル処理(音程補正・ディレイ・ハモリ加工) |
| ヒップホップ・トラップ | ○ | 808 はサイン波 + ピッチカーブでグライド、ハイハットの連打、パート分離でのサンプリング | 取り込み音声がモノラルになる(ステレオ感のあるサンプルが痩せる) |
| Lo-fi・チルホップ | ○ | SoundFont のエレピ、drum、パッド、AI がスウィングを測って書く | テープ・レコード風の質感エフェクト、UI でのスウィング一括適用 |
| ゲーム BGM・劇伴(小編成) | ○ | SoundFont のオーケストラ、Surge のパッド | GM 音源の質感、ストリングスの奏法(レガート等) |
| オーケストラ(本格) | △ | SoundFont | 音色の質・奏法の種類ともに不足 |
| ジャズ | △ | SoundFont のピアノ・ウッドベース・ドラム、和声解析・リズム解析 | アドリブの細かなニュアンス、生っぽい音色 |
| 弾き語り・生演奏中心 | △ | 録音、テンポ追従 | ステレオ録音、音程補正、複数テイクの編集 |

## 4. まとめ

- **得意なのはシンセ主体の電子音楽**。Surge + sidechain + オートメーションがそろい、AI がプリセット探しから
  つまみの微調整まで担える。
- **ポップス・ロック・劇伴は「作れるが音質は GM 音源なり」**。ピアノ専用・ストリングス専用などの高品質な
  SoundFont に替えると一段上がる。
- **生音・歌もの中心は苦手**。取り込み音声がモノラルになり、ボーカル向けの処理が無い。
- **AI の強みは「楽譜・理論・リズム・音の数値」を同時に見られること**。弱みは音の質感を直接は聴けないことなので、
  音色の最終判断は人間の耳で行い、AI には「もっと明るく」「埋もれている」のように感想で伝えるのが効く。

## 5. 伸ばすと効果が大きいもの(優先順)

1. **センド / リターン**: 複数トラックでリバーブ・ディレイを共有する
2. **ステレオ音声**: 取り込み・録音・パート分離をステレオのまま扱う(今は `load_wav_mono` で平均してモノラル化)
3. **スウィング(グルーヴ)の一括適用**: AI は測って書けるが、UI から既存のノートにまとめて掛ける手段が無い
4. **CLAP への奏法の転送**: ビブラート・ベンドをピッチカーブに変換して送る
5. **似た音を作る力の強化**: 内蔵の音源の種類を増やす(FM・ウェーブテーブル)、エフェクト込みの自動合わせ、
   Surge のつまみの自動合わせ。これまでの調査と結果は [`AUDIO_ANALYSIS_RESEARCH.md`](AUDIO_ANALYSIS_RESEARCH.md)
