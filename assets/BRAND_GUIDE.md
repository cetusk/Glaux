# Glaux ブランドガイド

Version 1.0 / 2026-09-25

## ブランドの核

Glaux は、AIと共同作曲できる軽量なデスクトップDAWです。知恵を表すフクロウと、音の流れを感じさせる曲線、精密でシャープな輪郭を組み合わせます。

採用ロゴは「Glaux」のFlow文字ロゴを左、立ち姿の全身フクロウを右に置いた②です。フクロウは名前に向く左向きのまま使用します。表記は **Glaux**（Gのみ大文字）に統一します。

## 用途とファイル

| 用途 | ファイル | 背景 |
|---|---|---|
| リポジトリー・README・紹介画像の基本形 | `logos/glaux-lockup-white.png` | 白背景 |
| 明るい任意の背景に配置する基本形 | `logos/glaux-lockup-transparent.png` | 透過 |
| favicon | `icons/favicon.png` | 透過・顔のみ |
| アプリ内に常時表示するアイコン | `icons/glaux-app-icon.png` | 透過・全身・白フチ |
| 通常の全身アイコン | `icons/glaux-owl-full.png` | 透過・白フチなし |

favicon.pngは顔のみ版の高解像度原本です。16/32px専用データやICOではありません。実際の小さな表示で目元の判別性を確認してください。

## 配色

| 色 | 指定値 | 役割 |
|---|---|---|
| Dark | `#142332` / RGB 20, 35, 50 | 輪郭・ボディ・文字の主色 |
| Turquoise | `#25BDB1` / RGB 37, 189, 177 | 羽・瞳・xのアクセント |
| White | `#FFFFFF` / RGB 255, 255, 255 | 顔・胸・羽の白部・白フチ |

上記は今後の制作・実装に使う指定色です。現行PNGには生成時の微細な色差と輪郭のアンチエイリアスが含まれます。新規制作はベタ塗りを基本とし、光沢・グラデーション・発光を加えません。

## 配置と余白

- 基本ロゴは同梱画像の文字とフクロウの比率・距離を維持します。縦横比を固定して拡大縮小してください。
- ロゴの周囲には、文字Gの見える高さの1/4以上を目安に余白を確保します。これは運用の推奨値です。
- 単体アイコンの周囲には、見えるアイコン高さの1/8以上を目安に余白を設けます。耳や尾を切らないでください。
- PNGには既存の余白が含まれています。キャンバス端ではなく、見える図形を基準に配置します。
- 横組みロゴの表示幅は240px以上を初期目安とします。より小さい場所では文字を無理に縮めず、指定の単体アイコンを使います。

## 背景別の使い分け

- リポジトリーでは白背景の基本ロゴが安定します。ページがダークモードでも白い背景ごと表示します。
- 背景透過の基本ロゴと通常全身版は、白・淡色の背景に配置します。文字や体のダーク部分が埋もれる黒背景への直置きは避けます。
- アプリ内では白フチの全身版を使用します。暗色・黒背景でも外形が見えるようにします。画像自体の背景は透明です。
- faviconには顔のみ版を使用します。横組みロゴや全身版に差し替えません。

## 形状の扱い

眉のカーブ、瞳、くちばし、羽先、Flowロゴの字形とxの曲線を保ちます。左右反転、縦横の引き伸ばし、別フォントでの打ち直し、色の入れ替え、影や装飾の追加は避けてください。アイコンとロゴを重ねたり、文字の上に止まらせたりせず、採用済みの横組みを使います。

## データ仕様

同梱アセットはPNGのラスターデータです。SVG、編集可能なベクター、フォントファイル、ICOは含みません。元の採用アセット4点は再描画せずそのまま収録しています。基本ロゴ②の透過版のみ、内蔵画像生成による背景除去編集を行っています。

`asset-manifest.json`に寸法・用途・SHA-256を記録しています。透過版では背景だけを抜き、フクロウ内部の白い顔・胸・羽を残しています。
