# AI に渡すプロンプトの例

ゲームのプロジェクトで AI(Claude Code など)に Glaux アドオンを使わせるときに、そのまま貼り付けて使える
プロンプトです。`[ ]` の部分を自分のゲームに合わせて書き換えてください。

---

## 1. 最初の導入(1 回だけ)

```text
このプロジェクトに Glaux のアドオン(res://addons/glaux/)を入れました。
Glaux は別アプリの DAW で作った曲を、ゲームの中で鳴らして拍・マーカー・特定の音に同期させるための拡張です。

まず res://addons/glaux/AI_GUIDE.md を最後まで読んでください。以降、曲との同期はこの手引きの API と
決まりごと(時刻は GlauxPlayer の get_song_time() を基準にする、BPM から拍の長さを計算しない、
project.json を手で書き換えない など)に従ってください。

そのうえで次を確認してください:
1. res://addons/glaux/ に glaux.gdextension と bin/glaux_godot.dll があるか。project.godot の [editor_plugins] で
   res://addons/glaux/plugin.cfg が有効か(無効ならゲームを書き出したときに曲が入らないので、人間に有効にしてもらう)
2. 曲フォルダ [res://songs/Stage1.glaux] を GlauxPlayer で読み込めるか(load_song の結果と get_warnings)
3. その曲のトラック名(get_track_names)とマーカー(get_sections)の一覧

確認できたら、このプロジェクトの CLAUDE.md(無ければ作る)に「曲との同期は addons/glaux/AI_GUIDE.md に従う」
「使う曲・トラック名・マーカー名の一覧」を短く追記してください。まだゲームのコードは変えないでください。
```

## 2. 敵の動きを曲に同期させる

```text
[ステージ 1] の敵を曲に同期させたいです。res://addons/glaux/AI_GUIDE.md の実装パターンに従って実装してください。

- 曲: [res://songs/Stage1.glaux]
- 敵のシーン・スクリプト: [res://enemies/boss.tscn]
- やりたいこと:
  - [キック(トラック "Kick")が鳴るたびに弾を撃つ]
  - [弾を撃つ 0.5 秒前に予兆のエフェクトを出す]
  - [拍の頭で体が膨らむ(拍の中の位置で滑らかに)]
  - [マーカー「サビ」から攻撃パターンを激しくする]

守ってほしいこと:
- タイミングは GlauxPlayer の時刻(get_song_time / get_beat_position / シグナルの time 引数)を基準にし、
  フレームの delta の積算やタイマーで拍を数えない
- トラック名・マーカー名は get_track_names / get_sections で確認してから使う
- 実装したら、どう確かめればよいか(何を見れば音と合っていると分かるか)も教えてください
```

## 3. 入力の判定(音ゲーの判定)を作る

```text
プレイヤーの入力(アクション "[hit]")を曲の音に合わせて判定したいです。
res://addons/glaux/AI_GUIDE.md の「3-6. 入力の判定」に従って実装してください。

- 曲: [res://songs/Stage1.glaux]
- 判定の対象: トラック [ "Notes" ] の音(読み込み時に get_notes で一覧にする)
- 判定の幅: [Perfect ±40ms / Great ±80ms / Good ±120ms、それより外は Miss]
- 判定は get_song_time() と音の time の差で行う(シグナルの到着時刻は使わない)
- 通り過ぎて入力されなかった音は Miss にする
- 設定画面で latency_offset_ms(音と画面のずれの補正)をプレイヤーが調整できるようにする
```

## 4. うまく合わないとき

```text
曲と [敵の動き / 判定] が合っていない気がします。res://addons/glaux/AI_GUIDE.md の
「4. 守ること・落とし穴」と照らして、今のコードに当てはまるものがないか調べてください。
特に: シグナルの到着時刻を使っていないか、BPM から拍の長さを計算していないか、play() を _ready で
直接呼んでいないか、トラック名・マーカー名が曲と一致しているか。
それでも分からなければ、拍ごとに画面を光らせて目で確かめる仕組みを一時的に入れてください。
```

## 5. 曲を変えてほしくなったとき

```text
ゲーム側から曲は編集しません。曲に欲しい変更を、Glaux で直す人向けに具体的に書き出してください
(例: 「2 小節目からキックを 8 分で」「サビ前に 1 小節のブレイク」「予兆に使うのでハイハットを別トラック "HiHat" に」)。
```

## 6. 効果音を曲のキー・コードに合わせて鳴らす(WAV を使わない)

```text
効果音を WAV ではなく Glaux のアドオンで鳴らし、音程を BGM のコードに合わせたいです。
res://addons/glaux/AI_GUIDE.md の「3-8. 効果音を曲のコードに合わせ、拍にぴったり鳴らす」に従って実装してください。

- BGM: [res://songs/Stage1.glaux](今の BGM の GlauxPlayer)
- 効果音用の曲: [res://songs/SEKit.glaux](トラックごとに効果音の音色がある。名前は get_track_names で確認)
- 効果音用の GlauxPlayer を 1 つ追加し、sync_to に BGM の GlauxPlayer を設定する(効果音用では play を呼ばない)
- 鳴らし分け:
  - [敵の攻撃の音: 次の拍に play_note_at で。音程はその拍のコードの構成音(get_chord_note)]
  - [プレイヤーの入力の音: play_note ですぐ。音程はいまのコードの構成音を、コンボ段階に応じて上っていく]
- 今 WAV で鳴らしている効果音のうち、音程を合わせたいものから置き換える(音程が要らない音は WAV のままでよい)
- CLAP の音源のトラックは鳴らないので、使う前に get_warnings を確認する
```

## 7. 場面に合わせて曲を組み替える(ループ・展開の切り替え・楽器の足し引き)

```text
場面に合わせて BGM を組み替えたいです。res://addons/glaux/AI_GUIDE.md の「3-7b. 場面に合わせて曲を組み替える」に従って実装してください。

- 曲: [res://songs/Stage1.glaux]。マーカーの名前は get_sections で確認する
- 場面と鳴らし方:
  - [探索中: 「探索」の区間を繰り返す。ドラムは抜く(set_track_volume_db で -80)]
  - [敵に見つかったら: 次の小節の頭で「戦闘」へ切り替えて繰り返す。ドラムは 2 秒かけて戻す]
  - [ボスを倒したら: 今の区間を弾き切ってから「エンディング」へ(繰り返さない)]
- 拍に合わせて動くものは beat シグナルに従い、jumped シグナルで先読みを作り直す
- 曲のファイルは変えない(音量の足し引きは set_track_volume_db で)
```
